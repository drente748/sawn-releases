# دليل تفعيل صَوْن على الموقع (للنشر على sawnapp.example.com لاحقًا)

> هذا الدليل يُسلَّم لموقعك لاحقًا: نفس خطوات المعالج داخل التطبيق، مصاغة للعرض على صفحة الويب (صور لاحقًا).

## متطلبات التثبيت (Android 8.0+)

1. **تحميل APK** من صفحة التحميل الرسمية (رابط `.apk` الموقّع).
2. **التحقق من سلامة الملف**:
   ```
   certutil -hashfile Sawn-2.2.0.apk SHA256   # Windows
   sha256sum Sawn-2.2.0.apk                    # Linux/macOS
   ```
   قارن مع البصمة المنشورة (SHA-256) في بيان التحديث: `https://drente748.github.io/warden/updates/manifest.json`.
3. **السماح بالتثبيت من هذا المصدر** (مرة واحدة):
   - افتح الملف `.apk` ← «يحتاج إلى إذن لتثبيت تطبيقات غير معروفة» ← **الإعدادات** ← فعّل ← عُد للملف ← **تثبيت**.
4. **Play Protect**: «قد يكون هذا التطبيق غير آمن» ← **مزيد من التفاصيل** ← **التثبيت على أي حال**.
   - (Play Protect تحذير طبيعي لأي تطبيق مُحمّل من خارج المتجر — ليس دليلًا على ضرر.)
5. **التطبيق يفتح معالج التفعيل** تلقائيًا.

## خطوات المعالج (داخل التطبيق)

1. **السماح بالإعدادات المقيدة (Android 13+، sideload)**:
   - **معلومات التطبيق** ← قائمة **⋮** ← **السماح بالإعدادات المقيدة (Allow restricted settings)**.
   - عُد للمعالج — «تم ✓» يهتز احتفاليًا.
2. **إمكانية الوصول** (إلزامية) — حجب التطبيقات + الريلز/الشورتس. زر ← `Settings.ACTION_ACCESSIBILITY_SETTINGS` + فحص دوري.
3. **شبكة صَوْن المحلية (VPN)** (إلزامية) — حصري DNS فقط، لا يفحص زياراتك. `VpnService.prepare` + «لا ترى أي شيء».
4. **الإشعارات** (POST_NOTIFICATIONS) — ليصلك إشعار «الحماية تعمل».
5. **استثناء البطارية** (موصى به) — طلب مباشر → حوار نظام واحد؛ إن رفض: روابط OEM + «يمكنك التخطي».
6. **اختياري**: Always-on VPN · Private DNS الصارم (شرح الثغرة) · Device Admin (منع الحذف) · Notification access (كتم إشعارات التطبيقات المحجوبة).

## ملاحظات

- كل خطوة قابلة «للتخطي» إلا (2)(3) — ولا تشغيل حماية بدونها (رسالة واضحة).
- Play Protect لن يختفي — يُرشد المستخدم ولا يُختصر.
- لا إنترنت إلزامي؛ القوائم محلية؛ تحديث القوائم اختياري يدوي.
- النسخة 2.0 تبدأ نظيفة — لا ترحيل بيانات Warden 1.x.
